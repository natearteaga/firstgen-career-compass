# Assumptions and Limitations

This project is intended to support career exploration and skill planning. It should not be interpreted as a hiring prediction tool.

## Role Mapping Limitation

O*NET occupation titles do not always match the exact job titles used by students, employers, or job boards.

For the MVP, the Data Analyst role is represented using O*NET's Data Scientists occupation data. This is a useful structured proxy, but it may overrepresent advanced skills such as machine learning, statistical modeling, or data engineering compared with some entry-level data analyst roles.

Because of this, Data Analyst results should be interpreted as directional skill signals rather than a complete or exact description of entry-level data analyst hiring requirements.

## O*NET Data Limitation

O*NET is occupation-level data, not live job-posting data. It helps describe general occupational expectations, but it does not capture every employer's current entry-level requirements, local market differences, or the exact wording used in job postings.

For the MVP, O*NET is used as a structured proxy for role expectations. Results should be described as occupation-based skill signals, not a complete view of the live job market.

## Recommendation Limitation

The MVP should not claim to calculate a student's probability of being hired.

Skill-gap recommendations should remain transparent and traceable to the underlying data. They should be framed as planning support, not as hiring guarantees or official career advising.
